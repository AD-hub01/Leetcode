# LeetCode Solutions

This repository contains my accepted solutions to LeetCode problems. It serves as a collection of my coding practice, helping me improve my problem-solving skills, strengthen my understanding of Data Structures and Algorithms (DSA), and prepare for technical interviews.

## About

The solutions in this repository are primarily written in **C++** and are organized according to LeetCode's problem numbering format. Each folder corresponds to a single problem and contains its accepted solution.

## Repository Structure

The repository follows the naming convention:

```
0001-two-sum
0012-integer-to-roman
0102-binary-tree-level-order-traversal
0103-binary-tree-zigzag-level-order-traversal
0199-binary-tree-right-side-view
...
```

Each folder contains the source code for the corresponding LeetCode problem.
